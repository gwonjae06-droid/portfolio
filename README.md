# 이권재 포트폴리오

해수면에서 심해와 별빛으로 이어지는 정적 포트폴리오입니다. 소개, 프로젝트, 배움, 관심사를 읽는 흐름으로 구성했습니다.

## 실행

빌드나 패키지 설치 없이 정적 HTTP 서버로 루트 폴더를 제공하면 됩니다. ES 모듈을 사용하므로 `file://`로 직접 열기보다 HTTP 서버를 사용합니다.

## 인터랙션

- WebGL 수면: 여러 크기의 파형, 수면 법선, 반사 및 하이라이트를 실시간 계산합니다.
- 파동 물리: `wave-physics.mjs`의 유한차분 파동 시뮬레이션이 마우스·터치 입력을 받아 주변으로 파동을 전달하고 감쇠합니다.
- 튜브 인물: 같은 파동장의 높이와 기울기로 부력, 수평 이동, 회전을 계산합니다. 첨부받은 투명 PNG 원본을 사용합니다.
- 깊이 전환: 스크롤에 따라 수면과 빛이 사라지고 수중 입자가 별빛으로 이어집니다.
- 접근성: 동작 줄이기 설정에서는 자동 움직임과 파동 입력을 멈춥니다. WebGL이 없으면 가벼운 Canvas 수면으로 전환합니다.
- 화면 밖으로 내려가면 수면 렌더링과 파동 계산을 중지하고, 탭이 숨겨지면 애니메이션을 중지합니다.

## 내 인생 다이어리

`life-diary/`에서 일기, 기분, 수면·집중 시간을 기록하고 검색·백업할 수 있습니다. 기록은 이용자의 브라우저 localStorage에 저장되며 서버로 전송하지 않습니다. 자세한 저장·백업 방식은 해당 폴더의 README를 참고하세요.

## 검증

