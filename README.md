# 이권재 포트폴리오

해수면에서 심해와 별빛으로 이어지는 정적 포트폴리오입니다. 소개, 프로젝트, 배움, 관심사를 읽는 흐름으로 구성했습니다.

## 실행

빌드나 패키지 설치 없이 정적 HTTP 서버로 루트 폴더를 제공하면 됩니다. ES 모듈을 사용하므로 `file://`로 직접 열기보다 HTTP 서버를 사용합니다.

## 인터랙션

- WebGL 수면: 여러 크기의 파형, 수면 법선, 반사 및 하이라이트를 실시간 계산합니다.
- 파동 물리: `wave-physics.mjs`의 유한차분 파동 시뮬레이션이 마우스·터치 입력을 받아 주변으로 파동을 전달하고 감쇠합니다.
- 튜브 인물: 같은 파동장의 높이와 기울기로 부력, 수평 이동, 회전을 계산합니다. 첨부받은 투명 PNG 원본을 사용합니다.
- 깊이 전환: 스크롤에 따라 수면과 빛이 사라지고 수중 입자가 별빛으로 이어집니다.
- 접근성: 동작 줄이기 설정에서는 자동 움직임과 파동 입력을 멈춥니다. WebGL이 없으면 가벼운 Canvas 수면으로 전환합니다.
- 화면 밖으로 내려가면 수면 렌더링과 파동 계산을 중지하고, 탭이 숨겨지면 애니메이션을 중지합니다.

## 내 인생 다이어리

`life-diary/`에서 일기, 기분, 수면·집중 시간을 기록하고 검색·백업할 수 있습니다. 기록은 이용자의 브라우저 localStorage에 저장되며 서버로 전송하지 않습니다. 자세한 저장·백업 방식은 해당 폴더의 README를 참고하세요.

## 검증

```sh
node --test tests/*.test.*
```

파동 전달과 감쇠, 반복 자극의 안정성, 인물의 부력·회전 반응, 다이어리 백업 데이터 검증을 확인합니다.

## 프로젝트 상세 소개와 실제 미리보기

포트폴리오의 4개 프로젝트 카드에서 **자세히 보기**를 선택하면 전체 화면을 벗어나지 않고 다음 정보를 확인할 수 있습니다.

- 제작 동기, 실제 구현 기능, 설계 과정에서 고려한 점, 개발 상태, 관련 GitHub 링크
- GAME WORKS 안의 OChams 3D Battle(공개 웹 시연), CAMPUS LEGENDS(로컬 개발, 비공개 저장소), Oibung Trials(NeoForge Minecraft 모드) 구분
- MINDSCAPE, UNI-SURVIVAL, OChams의 **실제 공개 웹 페이지**를 선택 시에만 iframe으로 불러오기 (초기 로딩에는 포함하지 않음)
- 내 인생 다이어리는 브라우저에 저장된 개인 기록이 공개될 위험을 피하기 위해 **화면을 삽입하지 않고 새 탭에서 직접 열기**만 제공
- 각 프로젝트는 실제 공개 링크와 원본 코드 링크를 별도로 제공합니다. 외부 브라우저/사이트 정책으로 iframe 미리보기가 차단될 수 있어 대체 링크를 제공합니다.

## 제작 과정·개발 기록·향후 방향

새 섹션에서는 이 포트폴리오를 구성하는 WebGL 수면·파동 시뮬레이션, 수중 입자와 고래 실루엣, 마지막 별자리 연출을 기술과 함께 설명합니다. 최근 프로젝트 개선 기록은 2026년 10월의 확인 가능한 공개 작업을 바탕으로 한 **수동 업데이트 일지**이며, GitHub 활동을 자동 수집하지 않습니다. 향후 방향은 확정된 로드맵이 아닌 관심사로 표시합니다. 연락 경로로 공개된 GitHub 프로필만 제공하며 개인 이메일을 임의로 추가하지 않았습니다.

레이아웃과 상세 UI는 `portfolio-upgrade.css`, `portfolio-details.js` 파일에 분리했습니다. 기존 `experience.js`, `water-renderer.mjs`, `wave-physics.mjs`은 수정하지 않습니다.

### 수동 확인 항목

1. 프로젝트 카드 네 개에서 자세히 보기 → 닫기/Esc/바깥 영역 클릭을 확인합니다.
2. OChams·MINDSCAPE·UNI-SURVIVAL 팝업에서 실제 화면은 버튼 선택 후에만 로딩되는지 확인합니다.
3. 다이어리 팝업에서는 내부 iframe 없이 새 탭 링크가 제공되는지 확인합니다.
4. 제작 과정, 최근 기록, 향후 방향, GitHub 연락 링크를 확인합니다.
5. 360px 모바일 너비와 키보드/화면 읽기 도구를 점검합니다.
6. 기존 해수면 상호작용, 중층 바다, 고래, 마지막 Dream big. 별자리 표현이 유지되는지 확인합니다.
