# UNI-SURVIVAL · 캠퍼스 생존 도구

첨부된 유니서바이벌 HTML에서 **네 가지 도구만 추출한 독립 페이지**입니다.

- **과제 시간 계산기:** 예상 소요시간·마감 시각·작업 분할
- **팀플 역할 분배기:** 팀원 입력과 역할 안내
- **15분 공강 품앗이:** 시연용 교환 카드 및 연락 메시지
- **교수님 메일 도구:** 표현 점검과 이메일 예시 생성

## 실행
`index.html`을 브라우저에서 열거나 포트폴리오의 `/uni-survival/`에 접속하세요. Tailwind CDN·Lucide 아이콘 등의 외부 에셋을 사용하므로 인터넷 연결이 필요합니다.

## 주의
계산과 역할 배분은 편의를 위한 추정 또는 규칙 기반 추천입니다. 품앗이 게시판은 **로컬 데모 데이터**이며 실제 학생을 연결하는 서버가 없습니다. 메일 문구는 제출 전에 실제 수업 규정, 사실 관계 및 수신인을 직접 확인하세요. 데이터는 사용자의 브라우저 localStorage에 저장될 수 있으며, 다른 기기와 동기화되지 않습니다.

## 정리한 영역
중복 포트폴리오 허브, 공부 노트, 프로필 수정, 배포 가이드, 게시물 편집 UI를 제외하고 도구 실행 화면 중심으로 구성했습니다.
