# 내 인생 다이어리

날짜별 일기와 다섯 단계 기분, 수면·집중 시간을 기록하는 정적 웹 프로젝트입니다.

## 기능

- 날짜별 저장 및 수정, 월별 목록과 본문 검색
- 최근 14일 기분 그래프와 기록 전체의 수면·집중 평균
- JSON 백업 내려받기 및 복원 (동일 날짜는 현재 기록 유지)
- 저장하지 않은 내용을 두고 날짜를 바꾸면 확인
- 다른 탭에서 기록이 변경되면 새로고침을 안내하여 덮어쓰기 방지

## 저장 방식

기록은 현재 브라우저의 localStorage에만 저장됩니다. 서버나 GitHub로 전송하지 않으며 계정이나 기기 간 동기화는 없습니다. 브라우저 데이터를 지우기 전에 JSON 백업을 내려받아 주세요. 같은 브라우저 프로필을 쓰는 사람은 기록을 볼 수 있으므로 잠금이나 암호화 저장 기능으로 간주하지 마세요.

## 실행

정적 HTTP 서버에서 이 폴더의 index.html을 열면 됩니다. 외부 라이브러리나 빌드 과정이 필요 없습니다. GitHub Pages에서는 /portfolio/life-diary/ 경로로 제공됩니다.

## 지표

수면·집중 평균은 입력된 값만 사용하며 0시간은 유효한 값입니다. 기분 그래프는 오늘을 포함한 최근 14일만 표시하고 기록이 없는 날은 비워 둡니다. 통계는 개인 기록을 돌아보기 위한 요약이며 인과관계나 심리 진단을 추론하지 않습니다.
